# Zyconomes - Motores Matemáticos

Projeto pessoal de engenharia de software e educação financeira algorítmica. 
O Zyconomes é um ecossistema de calculadoras client-side projetado para erradicar o "achismo" das finanças pessoais.

## 🚀 Arquitetura e Engenharia (As Coisas Mínimas de um Projeto Pessoal)

Este projeto foi desenhado sob a filosofia de **Produto antes de Infraestrutura (P0)**, garantindo a viabilidade do MVP sem custos de servidor corporativo.

- **Frontend:** React + Vite (Monólito Client-Side).
- **Estilização:** Tailwind CSS (Utilitário e Responsivo).
- **Estado (Persistência):** JIT via LocalStorage e Context Hooks (Zero Custo de DB).
- **Conteúdo (Blog):** SSG (Geração Estática) via Markdown injetado, focando em SEO nativo.
- **Rastreabilidade:** DataLayer nativo para tracking granular de engajamento (Dwell Time, Cliques, Intenção).

## 🛠 As 5 Ferramentas Gratuitas
1. **Diagnóstico Financeiro:** Fluxo de caixa e taxa de poupança (Alvo > 20%).
2. **Juros Compostos:** Simulação de dobra patrimonial (Sem inflação no MVP).
3. **Reserva de Emergência:** Blindagem calculada sobre 6 meses de sobrevivência mínima.
4. **Amortização de Dívida:** Desmascaramento da Tabela Price.
5. **Independência (Fator Tempo):** Extração logarítmica da distância até a meta patrimonial.

## 👨‍💻 Skin in the Game
Desenvolvido com rigor arquitetural e foco em conversão e zero fricção. O sistema implementa nativamente métricas B2B de retenção e captura não-intrusiva de e-mails para validação de Product-Market Fit orgânico.
